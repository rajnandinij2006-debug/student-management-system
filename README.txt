CAMPUSFLOW — STUDENT MANAGEMENT SYSTEM (FRONTEND DEMO)

OPEN IN VS CODE LIVE SERVER
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html → Open with Live Server.
5. The app usually opens at http://127.0.0.1:5500.

No npm install, Node.js, Python, or MySQL is required for this frontend demo.

FEATURES
- Polished responsive dashboard, sidebar and summary cards
- Sample records on first open
- Add, view, edit and delete students
- Search by name, roll number, email, phone or course
- Course/status filters and sorting
- Frontend form validation and duplicate roll/email checks
- Pagination and CSV export
- Course directory, reports and settings screens
- localStorage persistence in the same browser

IMPORTANT
This is a frontend-only demo. It simulates CRUD with JavaScript and browser localStorage. It has no actual server or MySQL connection, no server-side validation, no shared records across devices and no authentication. It is appropriate for a static demo site. A real production system needs an API/backend and database.

FILES
index.html — page structure
style.css — design and responsive layout
app.js — demo records, CRUD, search, filters, sorting, CSV export and localStorage
